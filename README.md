# Van Dilek Halı Yıkama

**Yerel hizmet sektörü için performans ve SEO odaklı kurumsal web projesi**

🌐 **Canlı proje:** https://vandilekhaliyikama.com/

Van Dilek Halı Yıkama için mobil uyumlu, yerel aramalara odaklanan ve yapay zekâ sistemleri tarafından keşfedilebilirliği güçlendirilmiş web altyapısı üzerinde çalışmalar gerçekleştirildi.

## Çalışmalar

- Responsive kurumsal tasarım
- Yerel SEO içerik yapısı
- Teknik SEO optimizasyonları
- Sitemap ve robots.txt
- Schema.org yapılandırılmış verileri
- Sayfa başlığı ve meta açıklama optimizasyonları
- Performans iyileştirmeleri
- AI/LLM keşfedilebilirlik çalışmaları
- llms.txt ve llms-full.txt
- Markdown içerik alternatifi
- Agentic Browsing uyumluluğu çalışmaları
- Arama motoru indeksleme kontrolleri

## Teknolojiler

HTML5 · CSS3 · JavaScript · PHP · Responsive Design · Technical SEO · Schema.org · LLM/AI Discoverability
